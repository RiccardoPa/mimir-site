# MIMIR — sito vetrina

Sito di presentazione di MIMIR, assistente AI personale locale e vocale.
La demo è **simulata**: dialoghi scritti a mano, dati inventati.

## File
| File | A cosa serve |
|---|---|
| `index.html` | Struttura e testi della pagina |
| `style.css` | Colori, font, effetto vetro. La palette è in cima al file |
| `demo.js` | Le scene della demo (oggetto `SCENES`) e il cambio colore |
| `reactor.js` | Il reattore 3D con three.js (da sostituire con i prototipi) |

## Pubblicazione
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
Indirizzo: https://riccardopa.github.io/mimir-site/

Nessuna installazione necessaria: three.js e i font arrivano da CDN.

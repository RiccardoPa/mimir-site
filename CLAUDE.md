# Regole per Claude in questo progetto

## Come rispondere
- Rispondimi sempre in italiano, in modo semplice: sono alle prime armi.
- Dopo ogni modifica spiegami in 3 righe cosa hai cambiato.

## Tipo di sito
- È un sito statico per GitHub Pages: niente build, niente npm, niente framework.
- Solo HTML, CSS e JavaScript.
- Usa sempre percorsi relativi (es. `style.css`, `demo.js`, non `/style.css`).

## Stile grafico
- Stile futuristico, "liquid glass" (vetro semitrasparente con sfocatura).
- Font: **Orbitron** (titoli) ed **Exo 2** (testo).
- Palette: fucsia/nero e acqua/nero.
- I colori sono variabili CSS in cima a `style.css`: usa quelle, non colori scritti a mano.

## Demo (demo.js)
- La demo è simulata: mai dati personali reali, solo dati inventati.
- MIMIR è solo vocale: nella demo niente caselle di testo (niente `<input>` o `<textarea>` per scrivere).
